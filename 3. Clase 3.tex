\frame{
 \frametitle{3. \LARGE Parámetros de interés}
Para un universo $U$ de tamaño $N$, sea $y$ la característica de interés, entonces podríamos estar interesados en:
\begin{enumerate}
\item \textbf{Total}: $t_y=\sum_Uy_k$ (personas con cierta enfermedad)
\item \textbf{Media}: $\overline{y}_U=\frac{\sum_Uy_k}{N}=\frac{t_y}{N}$ (dinero)
\item \textbf{Proporción}: $p_U=\frac{\sum_Uy_k}{N}=\frac{t_y}{N}$ para $y_k=\{1,0\}$ (desplazados)
\item \textbf{Razón}:$R=\frac{t_y}{t_z}$. Unidades del producto por establecimiento con la intención de venderlo.
\end{enumerate}
\pause
Nótese que todos los parámetros pueden ser expresados como función de totales, por tanto hay un particular interés encontrar estimadores para este parámetro.
}

\frame{
 \frametitle{3. \LARGE Estimador de Horvitz-Thompson (1952)}
 Para un universo $U$ se desea estimar el total de una característica de interés $y$ denotado como $t_y$. Por ejemplo,
\begin{definicion}
Para $\theta=t_y=\sum_Uy_k$ se define: \\
$$\widehat{\theta}=\widehat{t}_{y,\pi}=\sum_{s_i}\frac{y_k}{\pi_k}$$

$\frac{1}{\pi_k}$ se denomina \textbf{\textit{Factor de expansión}}
\end{definicion}
\pause
Cada elemento se representa a sí mismo y a una fracción de la población.
}

\frame{
 \frametitle{3. \LARGE Estimador de Horvitz-Thompson (1952) \\ Propiedades}
\begin{resultado}
\begin{itemize}
\item $E(\widehat{t}_{y,\pi})=t_y$  \\
\item $V(\widehat{t}_{y,\pi})=\sum\sum_U\Delta_{kl}\frac{y_k}{\pi_k}\frac{y_l}{\pi_l}$ \\
\item $\widehat{V}(\widehat{t}_{y,\pi})={\Large\sum\sum_{s_i}\frac{\Delta_{kl}}{\pi_{kl}}\frac{y_k}{\pi_k}\frac{y_l}{\pi_l}}$
\end{itemize}
\end{resultado}
\pause
$\Delta_{kl}=\pi_{kl}-\pi_k\pi_l$, además $E(\widehat{V}(\widehat{t}_{y,\pi}))=V(\widehat{t}_{y,\pi})$
}


\frame{
 \frametitle{3. \LARGE Estimador de Horvitz-Thompson (1952) \\ Muestreo Aleatorio Simple}
\begin{resultado}
\begin{itemize}
\item $\widehat{t}_{y,\pi}=\sum_{s_i}\frac{y_k}{\pi_k}=\frac{N}{n}\sum_{s_i}y_k$
\item $V_{MAS}(\widehat{t}_{y,\pi})=\frac{N^2}{n}\left(1-\frac{n}{N}\right)S^2_{yU}$
\item $\widehat{V}_{MAS}(\widehat{t}_{y,\pi})=\frac{N^2}{n}\left(1-\frac{n}{N}\right)S^2_{ys_i}$
\end{itemize}
\end{resultado}
}

\frame{
 \frametitle{3. \LARGE Estimador de Horvitz-Thompson (1952) \\ Muestreo Bernoulli}
\begin{resultado}
\begin{itemize}
\item $\widehat{t}_{y,\pi}=\sum_{s_i}\frac{y_k}{\pi_k}=\sum_{s_i}\frac{y_k}{\pi}$
\item $V_{Ber}(\widehat{t}_{y,\pi})=\left(\frac{1}{\pi}-1\right)\sum_Uy^2_k$
\item $\widehat{V}_{Ber}(\widehat{t}_{y,\pi})=\frac{1}{\pi}\left(\frac{1}{\pi}-1\right)\sum_{s_i}y^2_k$
\end{itemize}
\end{resultado}
\pause

\textcolor{violeta}{\textbf{Ejercicio:} Para los ejercicios hechos en clase de MAS y Bernoulli calcule $\widehat{t}_{y,\pi}$ y $V_{Ber}(\widehat{t}_{y,\pi})$, este último vía definición y por el estimador dado por la expresión. Para ambas expresiones compruebe el insesgamiento del estimador.}
}

\frame{
 \frametitle{3. \LARGE Estimación de la media poblacional \\ Muestreo Aleatorio Simple}
\begin{resultado}
\begin{itemize}
\item $\widehat{\overline{y}}_U=\frac{\widehat{t}_{y,\pi}}{N}$
\item $V_{MAS}(\widehat{\overline{y}}_U)=\frac{1}{n}\left(1-\frac{n}{N}\right)S^2_{yU}$
\item $\widehat{V}_{MAS}(\widehat{\overline{y}}_U)=\frac{1}{n}\left(1-\frac{n}{N}\right)S^2_{ys_i}$
\end{itemize}
\end{resultado}
\pause
Al factor $\left(1-\frac{n}{N}\right)$ se le conoce como factor de corrección para poblaciones finitas.
}

\frame{
 \frametitle{\LARGE 4. Muestreo con reemplazo $PPT(p_k,m)$ \\ Estimador de Hansen-Hurwitz (1943)}
 \begin{resultado}
$$\widehat{t}_{y,MCR}=\frac{1}{m}\sum_{i=1}^m\frac{y_{k_i}}{p_{k_i}}$$
donde $p_{k_i}$ es la probabilidad de selección del elemento $k$. Cada elemento se representa así mismo y al resto del universo $\rightarrow$ promedio.
El mecanismo de selección es Acumulativo Total.
\end{resultado}

 }

 \frame{
 \frametitle{\LARGE 4. Muestreo $PPT(p_k,m)$ \\ Estimador de Hansen-Hurwitz (1943)}
 \begin{resultado}
\begin{align*}
E\left(\widehat{t}_{y,MCR}\right)&=E\left(\frac{1}{m}\sum_{i=1}^m\frac{y_{k_i}}{p_{k_i}}\right) \pause \\
& = \frac{1}{m}E\left(\sum_U\frac{y_{k}}{p_{k}}Z_k\right)  \\
& = \frac{1}{m}\sum_U\frac{y_{k}}{p_{k}}E\left(Z_k\right)  \\
& = \frac{1}{m}\sum_U\frac{y_{k}}{p_{k}}m{p_k}  \\
& = \sum_U y_k = t_y
\end{align*}

\end{resultado}

 }


 \frame{
 \frametitle{\LARGE 4. Muestreo $PPT(p_k,m)$ \\ Estimador de Hansen-Hurwitz (1943)}
 \begin{resultado}

$V\left(\widehat{t}_{y,MCR}\right)=\frac{1}{m}\sum_Up_k\left(\frac{y_k}{p_k}-t_y\right)^2$\\[0.5cm]

$\widehat{V}\left(\widehat{t}_{y,MCR}\right)=\frac{1}{m(m-1)}\sum_{i=1}^m\left(\frac{y_{k_i}}{p_{k_i}}-\widehat{t}_{y,MCR}\right)^2$ \\ [0.5cm]

$E\left(\widehat{V}\left(\widehat{t}_{y,MCR}\right)\right)=V\left(\widehat{t}_{y,MCR}\right)$

\end{resultado}

 }

\frame{
 \frametitle{\LARGE 5. Confiabilidad}
\begin{definicion}
Sea $S$ el conjunto de todas las muestras posibles $s_1,\ldots,s_Q$; para el diseño $P(s_1), \ldots, P(s_Q)$ $\left[\sum_{s_i \in S}p(s_i)=1\right]$; el parámetro $\theta$ $\left[\theta:U\rightarrow \mathbb{R}\right]$ y el estimador $\widehat{\theta}(s_i)$.\\[0.3cm]
\pause
Para cada muestra se construye el intervalo $\left(LI(s_i), LS(s_i)\right)$ de tal manera que cada muestra tiene su propio intervalo y la longitud del intervalo puede variar dependiendo de la muestra. \pause

Se define \textbf{\textit{confiabilidad}} como la suma de las probabilidades de las muestras de las muestras cuyo intervalo de confianza cubre al parámetro:\\[-0.3cm] \pause
$$\sum_{\theta \in \left(LI(s_i), LS(s_i)\right)}P(s_i)$$
 \pause
\end{definicion}
Cuando se habla de confiabilidad se habla de la confiabilidad del intervalo NO de la muestra.
 }


 \frame{
 \frametitle{\LARGE 5. Confiabilidad \\ Propuesta de Intervalos}

\begin{itemize}
\item $\widehat{\theta}\pm z_{1-\alpha/2}\sqrt{V(\widehat{\theta})}$, por TLC se tiene que:
\begin{center}
$P\left(\theta \in \widehat{\theta}\pm z_{1-\alpha/2}\sqrt{V(\widehat{\theta})}\right)=1-\alpha,$  si $E(\widehat{\theta})=\theta$.
\end{center} \pause
Este intervalo presenta dos inconvenientes:
\begin{enumerate}
\item Condición de estimador insesgado
\item Se necesita la varianza del estimador y esa sólo se conoce en la teoría porque en la práctica solo se conoce cuando es censo y en ese caso no tiene mucho interés.
\end{enumerate}
\end{itemize}

 }


 \frame{
 \frametitle{\LARGE 5. Confiabilidad \\ Propuesta de Intervalos}

\begin{itemize}
\item $\widehat{\theta}\pm z_{1-\alpha/2}\sqrt{\widehat{V}(\widehat{\theta})}$ \\ \pause
Este intervalo presenta la cualidad de que en la práctica puede calcularse, lo que interesa es entonces es ¿Qué confiabilidad tiene?. \\ \pause

Puesto que los estimadores vistos son insesgados tanto para el parámetro de interés como para la varianza se espera que para $z_{1-\alpha/2}=1.96$ en un $95\%$ de las muestras el intervalo contenga el parámetro. Pero lo anterior no me garantiza que el parámetro esté en el intervalo de la muestra seleccionada.
\end{itemize}
\textcolor{red}{Ejercicio confiabilidad para los dos tipos de intervalo}
 }


 \frame{
 \frametitle{\LARGE 5. Confiabilidad \\ Sesgo Relativo}

La confiabilidad es una medida que se ve directamente afectada por el sesgo\footnote{medibles y no medibles} NO por el margen de error. Es decir, si $E(\widehat{\theta})\neq \theta$ la cobertura del intervalo decrece y por más de que $z_{1-\alpha/2}=1.96$ la cobertura puede ser muy baja.

$$B_r(\widehat{\theta})=\frac{B(\widehat{\theta})}{\sqrt{V(\widehat{\theta})}}=\frac{E(\widehat{\theta})-\theta}{\sqrt{V(\widehat{\theta})}}$$
\pause
\begin{ejemplo}
Para el ejercicio de clase imprima sesgos de $0; 0.05; 0.1; 0.3; 0.5; 1; 1.5; 2$ y usando un nivel de confianza del $95\%$ calcule y grafique la confiabilidad real. Use: \\
$$E(\widehat{\theta})-\theta=B_r(\widehat{\theta})\sqrt{V(\widehat{\theta})}$$
\end{ejemplo}
}


 \frame{
 \frametitle{\LARGE 6. Muestreo de Elementos \\ Estimación de un dominio}

\begin{definicion}
Con frecuencia se desean estimaciones de subpoblaciones no consideradas dentro del diseño muestral, dicha subpoblación es denominada un \textbf{dominio}, en general no sabemos cuántos elementos pertenecen a un dominio hasta obtener los resultados de la muestra. Por ejemplo, al diseñar una muestra para medir la intención de voto de los Colombianos el interés se centra en conocer el total de personas que votarán por los diferentes candidatos pero previo a los resultados no se conoce cuántos votarán por cada uno.
\end{definicion}
}


 \frame{
 \frametitle{Estimación de un dominio: Parámetros \\ Notación}

\begin{enumerate}
\item El total de un dominio es: $\sum_{Ud}y_k$, con $U_d$ la población que compone al dominio.
\item Sea $$y_{dk}=\begin{cases}y_k \hspace{0.2cm}\text{si } k\in U_d \\ 0 \hspace{0.4cm} \text{en otro caso}\end{cases}$$
\item Así $t_{yd}=\sum_{U}y_{dk}$ será el total de la variable de interés.
\item Si $y_{dk}=1$ cuando $k \in U_d$ entonces $N_d=\sum_Uy_{k_d}$ es el tamaño poblacional del dominio.
\item Luego la media del dominio es: $$\overline{y}_{Ud}=\frac{t_{yd}}{N_d}$$.
\end{enumerate}

}

 \frame{
 \frametitle{Estimación de un dominio: Estimadores \\ Notación}

\begin{ejemplo}
\begin{enumerate}
\item A nivel general el estimador de Horvitz-Thompson es:
$$\widehat{t}_{yd}=\sum_{s}\frac{y_{dk}}{\pi_k}$$
\item Particularmente para MAS se tiene que:\\[0.5cm]
$\widehat{t}_{yd}=\frac{N}{n}\sum_{s}y_{dk}$\\[0.5cm]
$\widehat{V}(\widehat{t}_{yd})=\frac{N^2}{n}\left(1-\frac{n}{N}\right)S^2_{y_ds}$
\end{enumerate}
\end{ejemplo}

}

bajo MAS
\begin{itemize}
\item $\overline{y}_{Ud}=\frac{t_{yd}}{N_d}=\frac{N/n\sum_{U}y_{dk}}{N_d}$

$\widehat{V}(\overline{y}_{sd})=\frac{1}{n_d}\left(1-\frac{n}{N}\right)S^2_{y_{sd}}$

 \frame{
 \frametitle{Muestreo Estratificado \\ Definiciones}
 \begin{definicion}
 \begin{enumerate}
\item Para $U=\{1,2,\ldots,N\}$ sea $\{U_1, U_2, \ldots, U_H\}$ una partición de $U$.
\item Para $U_h, h=1,\ldots,H$ se aplica de forma \textit{\textbf{INDEPENDIENTE}} el diseño muestral $P_h(\cdot)$.
\item Entonces $t_y=\sum_Uy_k=\sum_{h=1}^Ht_{yh}$ de tal manera que el estimador insesgado de $t_y$ es:
\begin{align*}
\widehat{t}_y=\sum_{h=1}^H\widehat{t}_{yh}
\end{align*}
\begin{align*}
\widehat{V}\left(\widehat{t}_y\right)=\widehat{V}\left(\sum_{h=1}^H\widehat{t}_{yh}\right)=\sum_{h=1}^H\widehat{V}\left(\widehat{t}_{yh}\right)
\end{align*}
 \end{enumerate}
 \end{definicion}
 }

 \frame{
 \frametitle{Muestreo Estratificado \\ Observaciones}
 \begin{observacion}
 \begin{enumerate}
\item Cada estrato $U_h$ es de tamaño $N_h$, así $\sum_{h=1}^HN_h=N$.
\item Una partición de $U$ es:
 \begin{itemize}
 \item $N_h\neq0, h=1,\ldots,H.$
 \item $U_i \bigcap U_j=\emptyset, i\neq j; i,j=1,\ldots,H$
 \item $\bigcup_{h=1}^HU_h=U$
 \end{itemize}
\item \textcolor{red}{Estrato es diferente de dominio}, los estratos se construyen a partir del diseño de la muestra, los dominios no. Por tanto la manera de hacer estimación es diferente.
 \end{enumerate}
 \end{observacion}
 }

 \frame{
 \frametitle{Muestreo Estratificado \\ Razones para estratificar}
 \begin{observacion}
 \begin{enumerate}
\item Minimizar varianza. Por ejemplo, para estimar personal ocupado el DANE en las encuestas económicas  estratifica por empresas grandes, medianas y pequeñas.
\item Necesidad de contar con información con alta precisión para algunos niveles de desagregación. Por ejemplo, en un estudio en Bogotá se desean estimaciones por localidad pero de no controlarse la muestra es posible que salgan muy pocos elementos para algunas localidades. Es importante tener en cuenta que si la razón es esta el cálculo del tamaño de la muestra se haga de manera independiente para cada estrato.
\item Reducción de costos. Por ejemplo, los gastos de desplazamiento pueden llegar a aumentar de manera considerable los costos de un proyecto entonces es posible estratificar por ciudades grandes, intermedias y pequeñas.
\end{enumerate}
\end{observacion}
}

 \frame{
 \frametitle{Muestreo Estratificado \\ Problemas técnicos de estratificar}
 \begin{observacion}
 \begin{enumerate}
\item La cantidad de estratos es inversamente proporcional a la varianza y proporcional a los costos. En general al llegar a determinado número de estratos no se gana mucho en disminuir varianza y por el contrario se invierte mucho dinero.
\item Delimitación de los estratos (Hidroglou, Dalenius, Análisis multivariante de clúster).
\item Variable de estratificación - ¿con respecto a qué variable se debe estratificar?.
\item Asignación de muestra por estratos.
\end{enumerate}
\end{observacion}
}

 \frame{
 \frametitle{Muestreo ESTMAS}
 \begin{ejemplo}
Un caso particular es cuando se estratifica y cada uno de los estratos se aplica de manera independiente un $MAS(N_h,n_h)$. Encuesta de Anual de servicios, manufacturera y comercio (DANE).
\begin{itemize}
\item $\widehat{t}_{yh}=\sum_{sh}\frac{N_h}{n_h}y_k$
\item $\widehat{t}_{y}=\sum_{h=1}^H\widehat{t}_{yh}=\sum_{h=1}^H\sum_{sh}\frac{N_h}{n_h}y_k$
\item $\widehat{V}\left(\widehat{t}_{yh}\right)=\frac{N_h^2}{n_h}\left(1-\frac{n_h}{N_h}\right)S^2_{ysh}$
\item $\widehat{V}\left(\widehat{t}_{y}\right)=\sum_{h=1}^H\widehat{V}\left(\widehat{t}_{yh}\right)=\sum_{h=1}^H\frac{N_h^2}{n_h}\left(1-\frac{n_h}{N_h}\right)S^2_{ysh}$ \end{itemize}
\end{ejemplo}
}

 \end{ejercicio}
